Your stocks.
Your terminal.

Stonks is a terminal-based stock visualizer and tracker that displays realtime prices in graph format, right in your command line.

Get Started View Source

Features

Terminal charts

Track stock price movement with lightweight, readable console graphs.

Saved favorites

Save a watchlist and load it anytime with a single command.

Multiple timeframes

View daily, weekly, yearly, or custom-date snapshots from the same tool.

Install

Clone the repo and build it with Go: 

git clone https://github.com/SeanK-schoolalive/stonks.git
cd stonks
make

Or install from the GitHub releases page.
